# Pumpkin Jam · 午夜怪物乐队

完整的静态万圣节音乐游戏，供 [sprunki-game.top](https://sprunki-game.top) 专题接入。属于 Midnight Candy Club 系列。角色、视觉和浏览器合成音色均为本项目原创，并非外部 Sprunki 游戏的修改版。

## 运行

```sh
python3 -m http.server 4173
# 打开 http://localhost:4173
npm test
```

无需安装依赖或构建。请通过 HTTP 服务打开，以加载 ES modules。

## 完成的体验

- 4 个声部、8 个原创角色，96 BPM / C 小调。传统角色混音加入了三个隐藏乐队组合。
- Web Audio 前瞻调度使用 AudioContext 的绝对时钟；角色变化在下一小节同步进入。
- 独奏、各声部静音、主音量、三组预设；音频仅在用户操作后启动。
- “幽灵回声”是五轮传统序列记忆小游戏，用同一组音乐角色呈现。
- 分享链接恢复角色与静音配置，接收者主动点击播放。不会上传音频。
- 英文与简体中文，触屏点击与桌面拖放，减少动态效果偏好支持。
- 编曲、发现的组合与回声进度保存在当前浏览器。存储不可用时仍可游玩。

## 审查

`npm test` 检查全部编曲组合编码、无效链接、隐藏组合条件、音频时间换算、乐谱范围和回声序列判定。另有真实音频类的模拟时钟测试，覆盖后台冻结 60 秒及更长时间、过期拍跳过、下一小节切换、暂停中的音频时钟、异步播放/回声取消；页面隐藏后不会自动恢复播放。声音是程序合成，实际设备的音色与延迟需要浏览器试听评估。浏览器或系统静音会影响播放；没有声称测得真实声学延迟。

本项目没有账户、广告、外部音频、第三方 iframe 或网络请求依赖。代码中无生产密钥。
